## NEXT SESSION — the deposition-only model test (new branch)

A **boundary condition**, run thoroughly. Remove transport entirely (`q = 0`, a
clean nested special case: `rcw = rc0` makes `fc` irrelevant) so the model only
deposits new material; abandon the Moffat assumption and test the profile
families. Design constraints, all measured:

1. **Run it GRADED, not binary** — profile the loss over `q` (fitted at 0.908 in
   a [0,3] box, comfortably interior, so the data actively WANTS transport under
   the present setup) with `q` = 0 as the endpoint.
2. **The efficiency window MUST be free.** Transport and the window are
   entangled: with sig = 0.235 late deposits are nearly massless, so a
   no-transport model would have no way to change shape at late times and the
   failure would be uninterpretable.
3. **Judge against the MEASURED added-light kernel, not the loss.**
   `exp38/outputs/stage0_kernels.npz` holds it (3 mass terciles x 4 epoch pairs
   x 23 radii); exp38 stage 0.2 measured it as **centrally peaked at 3–4 kpc,
   Sersic n = 2.1–3.1, half-mass radius 15–47 kpc** — NOT a shell.
4. **Quantitative scorecard** (exp52, n=2397): median dlogSigma ~ 0.00 +/- 0.01
   at 2–3 kpc for both z<1 pairs; **+0.09 at 2.35 kpc over the long baseline**
   (the core GROWS); slope b ~0.10 late rising to 0.15–0.19 early; **all
   essentially independent of halo mass**.
5. **Sersic was rejected for a FIXABLE reason** — exp38 stage 1 killed it with
   "LOWER rail 3/5 epochs (n-scale degeneracy; needs an R50 reparameterization)",
   which is exactly the defect exp49 characterized. The family the measured
   kernel points at was eliminated by a numerical artifact.
6. **Falsifiable prediction**: exp52 showed transport drains M(<10 kpc) to 57.3%
   of the truth's growth. Removing transport should IMPROVE central masses. If it
   does not, exp52's mechanism story is wrong.
7. A **300 kpc deposit-radius ceiling is free** (1.5e-5) and worth carrying, and
   it matters MORE for a fair family comparison since `rc` is not the same
   physical quantity across families.
