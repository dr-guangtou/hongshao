# Session Handover — 2026-08-25

## Goal

**The next session does B1: genuine profile likelihoods for the seven adopted
parameters.** Everything below exists to make that step well posed and to say
what is already known about it.

Every identifiability statement this experiment has ever made is a
**conditional slice** — one parameter is displaced while the other six are held
FIXED. A profile likelihood re-optimises the other six at every grid point. In
a correlated model the two differ badly: a conditional slice can rise steeply
along a direction the profiled curve leaves nearly flat, so the conditional
version systematically **overstates** how well determined a parameter is.
`fit.py`'s own docstring says this and says not to quote it as evidence on its
own. It has never been done.

## Problems / Blockers

- **`log_f0` may profile into its bound at 0.** Report it as a bound, not as a
  likelihood feature.
- **Nelder-Mead in 6 dimensions needs multiple starts**; start each grid point
  from the incumbent with the fixed parameter moved, and from the neighbouring
  grid point's solution (a continuation sweep), so the profile is smooth rather
  than noisy.
- **Do not report the profiled curve as a confidence interval** without saying
  what the loss is: it is a weighted sum of two normalised scores, not a
  log-likelihood, so a `Δloss` threshold has no distributional meaning here.
  Quote it as "how much worse the best achievable fit becomes".

## Key Decisions

- **The deposition-only limit is reported as a limit**, not rescued by fitting
  the non-declining subset alone (user's call, 2026-08-25).
- **The expansion mechanism is deferred**, not rejected: let each deposit expand
  homologously after it is laid down, both radii scaled by `g = (t_k/t_j)^alpha`
  — mass conserved, nothing negative, no stellar input, `alpha = 0` nests the
  current model, and `M*(<R)` can then decrease. It **changes the model class**
  (Stage 0's monotone-in-time assertion becomes conditional, and the basis
  starts depending on the viewing epoch). Tech note Section 10.2 item 3b.
- **Nothing from Stages 3.5-3.8 was adopted.** The incumbent stands.
- Nested starts now lift **by parameter name**, gated by `assert_lift_nests`;
  positional splicing was silently wrong for parameters appended at the end.
